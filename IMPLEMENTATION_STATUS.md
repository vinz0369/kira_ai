## Phase 3 - IMPLEMENTED

### Browser voice input

- `@ricky0123/vad-web` runs the self-hosted Silero VAD v5 model in an AudioWorklet.
- Microphone constraints request mono capture, echo cancellation, noise suppression, and automatic gain control.
- Detected turns include about 192 ms pre-roll and are sent as versioned, bounded PCM16 frames over the authenticated dashboard WebSocket.
- Duplicate, out-of-order, oversized, wrong-direction, and wrong-turn frames are rejected or counted as dropped. Raw microphone audio is not persisted.

### Provider pipeline

`browser mic -> Silero VAD -> Deepgram streaming STT -> Conversation Director -> selected FPT Chat Completions or OpenAI Responses adapter -> selected TTS adapter -> PCM16 binary WebSocket -> OBS overlay`

- Pipecat 1.12.0 owns the Deepgram streaming service lifecycle. Defaults are `nova-3-general` and Vietnamese `vi`.
- FPT Marketplace Chat Completions is the default real LLM for new characters. The backend-only key, official gateway, streaming model, timeout and model allowlist are configurable; default model is `Saola-Small-32B`. The adapter consumes streaming deltas and terminal token usage, closes cancelled streams and uses the existing pre-output retry/degraded fallback. Existing characters remain on OpenAI after migration.
- A live Deepgram 400 was traced to Pipecat connecting with `sample_rate=0` before setup and an older `utterance_end_ms=900` configuration. The adapter now initializes 16 kHz before connecting and clamps the latter to 1000 ms. The real WebSocket probe connected successfully.
- OpenAI Responses streaming emits text deltas using the environment-configured model, default `gpt-5.4-mini`, with `store=false`. Official OpenAI documentation marks the former `gpt-5-mini` default deprecated.
- Google Cloud Text-to-Speech streams PCM using the environment-configured Chirp 3 HD voice, default `vi-VN-Chirp3-HD-Leda`.
- gTTS 2.5.4 supplies the default credential-free Vietnamese option. Edge TTS 7.2.8 supplies opt-in Hoài My/Nam Minh voices and is explicitly experimental; 7.3.0 was rejected after returning no audio locally.
- gTTS/Edge MP3 is decoded in memory through PyAV to PCM16 mono 24 kHz. No alternate browser playback path or runtime audio file is introduced.
- Provider credentials exist only in backend configuration. Voice Real requires Deepgram and the selected LLM; Google credentials are required only when that character selects Google Chirp.
- STT disconnects drop live mic frames rather than replaying stale audio. OpenAI retries once only before any output. TTS failure uses an explicitly degraded local PCM fallback.

### Conversation, cancellation, and audio safety

- The Vietnamese personality prompt is layered separately from bounded context and wraps chat/donation text as untrusted data.
- Context memory is bounded and process-local; persistent memories remain opt-in behavior from the existing design.
- Streamer barge-in, mute, pause, and stop cancel the generation task even if `speech.start` has not yet been emitted.
- Overlay playback is exactly-once per utterance. Cancellation stops every scheduled Web Audio source; reconnect sends state only and never replays old audio.
- The 3D renderer uses demand rendering at 10 FPS idle and 20 FPS speaking, preserving idle/talking motion while avoiding resource starvation in browser-source use. The procedural model remains the load-failure fallback.

### Telemetry and cost

- Session usage reports STT seconds accepted by the STT pipeline, provider-reported LLM input/output tokens, TTS text submitted, provider errors, reconnect episodes, dropped mic frames, and optional operator-configured cost estimates. `usage_basis` prevents treating these counters as provider invoices.
- Timings cover event-to-decision, LLM first token/complete, TTS first audio, overlay playback ACK, event-to-first-playback ACK, and cancellation dispatch/ACK/audio-stop latency.
- Active STT usage is visible before disconnect. Missing cost rates produce `estimated_usd: null`, not a fabricated price.
- Voice latency now starts at the server receipt of browser VAD end: `stt_final_ms` measures VAD end to final transcript and `voice_end_to_first_playback_ack_ms` measures VAD end to overlay playback-start ACK.
- Usage includes observed duration and an optional 3-hour run-rate projection for Voice Real after at least 60 seconds. It never projects from Mock Mode.
- Credential-free TTS contributes a zero TTS rate; STT and LLM rates are still required before cost projection is shown.
- FPT and OpenAI use separate, optional per-million-token cost rates. The 10-turn benchmark estimates FPT LLM cost from the live `/v1/models` catalog; app-session estimates stay unknown until the operator configures rates, and neither value is an invoice.
- Scopes distinguish `PREFLIGHT_ONLY`, `MOCK_SIMULATED_LOCAL`, `SIMULATED_PROVIDER_LOCAL`, `REAL_PROVIDER_LOCAL`, and per-trace `DEGRADED_FALLBACK_LOCAL`. Fallback E2E values are excluded from real-provider P50/P95.
- `/settings/diagnostics` provides safe provider readiness, an opt-in local mic-level check, real-session metric lookup, Vietnamese/gaming/persona/OBS checklists, and evidence JSON export.
